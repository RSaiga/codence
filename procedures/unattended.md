# unattended — 人が見ていない回の迷い方 / When no one is watching

`on_doubt` が `log` の回（`discipline.md` の任意の項目。その回の依頼の明示が設定に勝つ）に、`cycle.md` の「判断に迷ったら止まる」の代わりに使う。
規律は緩めない。変わるのは、迷ったときに止まるか、記録して進むかだけ。
Used instead of "when in doubt, stop" when `on_doubt` is `log`. No rule is relaxed; only what happens on doubt changes.

## 1. 迷いを 3 つに分ける / Three kinds of doubt

上から順に当てる。どれか分からなければ、上の側に入れる。

**止まる（人がいなくても止まる）** — 次のどれかに当たる、またはそうしないと進めないとき。`cycle.md` のとおり報告して止まる。
- 戻せない操作: 作業ブランチの外を変える（push、履歴の書き換え、別のブランチ）。`tdd.stack` の `reset` のほかの方法でデータを消す。自分が作っていないファイルを消す。
- 自分のものでないプロセスやポート（`tdd.md`「スタック」）。
- 最初が緑でない。作業と関係のない差分がある。リストが無い・書けない。スタックが用意できない。テストのスイートが走らない。
- コミットのフックが落ちる。触っていないファイルを切り分けられない。
- 設定・CI・フック・権限・依存するパッケージを変えないと進めない。
- 保留が続けて 3 件になった（同じ原因で詰まっている見込みが高い）。
Stop for anything irreversible, anything not yours, anything that keeps the loop from starting, and after three parks in a row.

**保留して次へ** — `cycle.md` の止まる条件のうち、上に無いもの（出典が無い・食い違う、意図した理由で落ちない、テストが間違っていると判断した、
大きな構造の変更が要る、既存のテストが落ちてリストに無い、どのシナリオにも無い振る舞いを求める、観点が `STOPPED` か 3 回目の `FINDINGS`、同じ項目で 2 周しても進まない）。
1. 記録に書く（2）。
2. その項目（二重ループではそのシナリオ）の、最後のコミットのあとの変更を `git stash push -u -m "codence D<n>"` で退避する。捨てない。何も変えていなければしない。
3. 最後のコミットの状態で、触った範囲の `fast` のスイートが緑であることを確かめる。赤なら止まる。
4. リストの印を `[ ]` に戻し、その行の末尾に ` — 保留 D<n>` を足す。進行中のタグを付けてコミットしたシナリオは、タグを残す（既定の実行から外れたまま）。
5. その項目に頼る項目（同じシナリオの残り、それを前提にする項目）も、同じ番号で保留にする。頼らない次の項目かシナリオへ進む。
Park: log it, stash the item's uncommitted work, confirm green at the last commit, mark the line, park what depends on it, move on.

**決めて進む** — 上の 2 つに当たらないが迷うとき（手順に書かれていない状況で、やり方が 2 つある など）。
戻せる方を選ぶ: データを消さない方、既存の振る舞いを変えない方、変更の小さい方、近くの書き方に合わせる方。記録に書いてから進む。
Otherwise pick the reversible option, log it, and go on.

## 2. 判断の記録 / The decision log

`.codence/decisions/<ブランチ>.md`（ブランチ名の `/` は `-`）。無ければ作る。決めた・保留したそのときに 1 件ずつ書き足し、前の件を書き換えない（中断しても残る）。
```
## D<n> <決めた | 保留> — <項目かシナリオ>
- 迷ったこと: <何と何で迷ったか。当たった止まる条件があれば、その条件>
- 選んだもの: <選んだやり方。保留なら「保留」と、同じ番号で保留にした項目>
- 理由: <その方を選んだ根拠と、見たもの（ファイル・出力）>
- 戻し方: <revert するコミット、または stash の "codence D<n>">
- 確かめ方: <人があとで見るもの（テスト・ファイル・コマンド）>
```

## 3. 報告 / Report

`cycle.md` の報告の最後の塊に、次の 1 行を足す。止まった理由が「リストが尽きた」でも、保留があれば「リストが尽きた（保留 <n> 件）」と書く。
```
判断:     D1 決めた <1 行> / D2 保留 <1 行>（記録: .codence/decisions/<ブランチ>.md。無ければ「なし」）
```

**しないこと / Never:** 「止まる」に当たるものを決めて進むこと。保留した変更を捨てること。進むために規律（落ちるのを見てから実装、緑からだけコミット など）を緩めること。
